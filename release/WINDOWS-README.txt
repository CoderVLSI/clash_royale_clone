Clash Royale 3D - Windows (x86_64)
Keep ClashRoyale3D.exe and ClashRoyale3D.pck in the same folder, then run ClashRoyale3D.exe (no install). Windows 10/11, OpenGL 3.3 capable GPU.
Mouse controls: drag a card from the hand onto your half of the arena to deploy it.
Save data is stored in %APPDATA%\Godot\app_userdata\Clash Royale 3D\
